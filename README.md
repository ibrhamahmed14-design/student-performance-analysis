# 📊 Student Performance Analysis

A Python project that simulates student records, assigns grades based on marks, and analyzes academic performance using **Pandas**.

## 📌 Overview

This project generates random student data, evaluates each student's performance, and provides useful statistics such as pass rate, grade distribution, and the highest score for each subject.

The main goal of this project is to practice working with Python data structures and performing basic data analysis using Pandas.

---

## ✨ Features

* Generate random student records.
* Assign grades (A, B, C, D, F).
* Calculate the overall pass rate.
* Display the highest mark for each subject.
* Show grade distribution.
* Identify students who failed.
* Store successful students in a Pandas DataFrame.
